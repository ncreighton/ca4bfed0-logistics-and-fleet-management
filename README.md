# Logistics and Fleet Management Tracking Bot

Telegram bot for logistics managers and fleet operators tracking vehicle locations, delivery statuses, and driver performance. Dispatchers receive real-time delivery completion notifications, delay alerts with estimated new ETA, fuel stop logs, and daily driver activity reports. Drivers use the bot to submit proof of delivery photos, report mechanical issues, and request route changes. Features multi-fleet dashboard, weekly KPI digest, and automatic escalation to operations manager on 2-hour delivery delays. Integrates via webhook with GPS tracking systems and order management platforms.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
